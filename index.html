    How the pricing study works

    Inputs, calculation choices, and limits in practical terms.

    Deterministic browser model

    Calculation

    Each accelerator has a synthetic hourly price, drift, and dispersion. The browser generates seeded lognormal paths, then reports percentiles and workload-normalised comparisons. These are scenario ranges, not a live price forecast.

    Reproducibility

    The catalogue and price history are committed with the source. The same SKU, horizon, path count, and seed produce the same result.

    Limits

    • No provider API or broker feed is connected.
    • Availability, reservation terms, egress, support, and regional taxes are out of scope.
    • No historical forecast backtest or purchasing recommendation is claimed.
    • Values should be replaced with dated provider quotes before a real procurement decision.
